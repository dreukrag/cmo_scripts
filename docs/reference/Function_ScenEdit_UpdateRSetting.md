### <a name="ScenEdit_UpdateRSetting"></a>ScenEdit_UpdateRSetting (RealismSettingString, boolean)

This function enables/disables scenario realism settings

#### Parameters

- RealismSettingString = [RealismSetting](DataTypes.md#dataType_RealismSetting) The scenario realism setting
- boolean True/False Enables or disables the specified realism setting

#### Returns

True/False Returns True if the setting is valid

##### Example

`ScenEdit_UpdateRSetting("DetailedGunFireControl", true)`
