# Official CMO Lua API docs (Markdown mirror)

Everything in this folder except this README is generated by
`tools/fetch_cmo_docs.py` from the official Command Lua documentation at
<https://commandlua.github.io/> (© WarfareSims). It's mirrored so it can be
searched offline and read next to the scripts. **Don't edit these files by
hand.** Re-run the tool instead.

- `Overview.md`: the site's landing page (news/changelog, intro, event handling, error handling, globals, date/time)
- `Functions.md`, `Wrappers.md`, `Tables.md`, `DataTypes.md`, `Selectors.md`, `Examples.md`: the main sections
- `Function_*.md`: one page per API function

Upstream pages that return 404 (linked but missing): `UI_SelectThisUnit`,
`ScenEdit_PlayVideo`.
