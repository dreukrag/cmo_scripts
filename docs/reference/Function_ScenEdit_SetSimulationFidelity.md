## <a name="FunctioName"></a>ScenEdit_SetSimulationFidelity( fidelity )

**[PRO ONLY]**

The function's purpose to set the simulation 'fidelity'.

### Parameters

- fidelity valueValues are:  
  0.1  
  1  
  5  
  Set the simulation's 'fidelity'

### Returns

- Error message if there is one

#### Example

` local error = ScenEdit_SetSimulationFidelity( 1 ) `
